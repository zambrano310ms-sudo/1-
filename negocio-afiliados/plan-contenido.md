# Plan de contenido — Hogar Inteligente (Amazon España)

> Nicho: **Hogar inteligente / domótica**. Mercado: **Amazon.es**. Fase: **arranque** (sin PA-API hasta las 3 primeras ventas).
> Regla de oro: nada de precios ni specs inventados. En arranque se enlaza con "Ver precio en Amazon" (SiteStripe) sin cifra. Divulgación de afiliado visible en todas las páginas.

## Ángulo editorial

**"Domótica fácil para tu casa"** — guías y comparativas claras, sin tecnicismos, para gente normal que quiere una casa más cómoda/segura sin ser ingeniero. Tono cercano y práctico.

Por qué este ángulo: el grueso de las búsquedas en español son de gente que NO es experta ("cómo elegir", "mejor X calidad-precio", "fácil de usar"). Posicionarse como el sitio que lo explica fácil = menos competencia que las webs hiper-técnicas.

## Producto punta de lanza: robots aspirador

Es la mejor puerta de entrada del nicho:
- **Intención de compra altísima**: "mejor robot aspirador" se busca muchísimo en España.
- **Ticket alto** (50–1400€) → comisión decente incluso con el % bajo de Amazon.
- **Efecto carrito 24h**: quien investiga un robot suele comprar también bolsas, mopas, recambios → más pedidos = las 3 ventas llegan antes.
- **Evergreen** con renovación constante de modelos.

Productos candidatos reales a reseñar/comparar (specs y precios se rellenan luego con PA-API, NO ahora): Roborock (Saros/Qrevo), Cecotec Conga, Xiaomi Robot Vacuum, Dreame, Eufy, iRobot Roomba.

## Estructura del sitio (clusters)

1. **Limpieza inteligente** (spearhead) — robots aspirador, friegasuelos, limpiacristales
2. **Seguridad** — cámaras de vigilancia, videoporteros, cerraduras inteligentes, sensores
3. **Iluminación y energía** — bombillas inteligentes, enchufes, tiras LED
4. **Climatización** — termostatos, purificadores, deshumidificadores
5. **Control y ecosistema** — Alexa/Echo, Google, Matter, hubs, guías para principiantes

Cada cluster: 1 página comparativa "pilar" + reseñas individuales + guías "cómo elegir", todo enlazado entre sí.

## Tipos de keyword por intención

- **Comparativa / compra** (lo que más convierte): "mejor robot aspirador 2026", "mejor robot aspirador calidad precio", "robot aspirador menos de 200 euros"
